Metadata boundary

Production rule: tenant/user authorization metadata must come from trusted backend identity. The LLM should not be allowed to choose a tenant ID to search. This page exposes the fields only so you can visualize how candidate eligibility changes.

Metadata-aware retrieval

The vector store first removes documents that do not match these metadata constraints. Only then does it calculate cosine similarity and apply the minimum similarity threshold.
